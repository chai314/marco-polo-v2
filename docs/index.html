The same price from fewer paths

An option’s price is an expected payoff. Monte Carlo estimates it by simulating the stock many times and averaging the discounted payoffs. The estimate has no bias, but its error falls only like .

This page runs that estimator one path at a time. It then adds four variance-reduction methods, which give the same expectation with a smaller variance at the same number of paths.

Combining methods

The methods act on different parts of the estimator: A and S change how the normals are drawn, C corrects the output, and K replaces with a conditional expectation.       How the numbers are measured

      • The board is the engine’s paths. Balls are drawn from the same generator and model as the engine. For a European option the engine samples in one step, which is exact; the board shows intermediate dates from the same law. The gauge and every error come from the engine’s own estimates.
      • Reported errors can be too small. If the variance across repeated runs exceeds the mean reported variance by more than sampling noise allows (at least 25%), the observed variance is used and the page says so. This happens under jumps: a short run may contain no jump.
      • Two estimators are biased. Longstaff–Schwartz prices the American put with an estimated exercise rule, which is suboptimal, so it is biased low. A barrier monitored only on a grid misses crossings between dates. For both, variance is measured about the estimator’s own mean and the bias is reported separately.
      • Run times are rough. They come from one thread in your browser.
      • Data. Closes and option quotes for SPY, QQQ, IWM, AAPL, MSFT and NVDA at 24 November 2026 from Yahoo Finance, and the three-month Treasury yield from FRED. The page can also generate a synthetic market, and says so when it does.
      • Checks. Every price is compared with one that was not simulated: Black–Scholes, Merton’s series, numerical integration for the arithmetic Asian, Reiner–Rubinstein for barriers and a lattice for the American put. The WebAssembly engine agrees with the native C++ to nine digits.
